## Réutilisation

Licence MIT : copiez, adaptez, traduisez. Tout le contenu est dans `fiches.mjs`, et `node build.mjs` produit le site dans `docs/`. Une correction ou une idée de fiche ? Ouvrez un ticket.

Ces fiches donnent des modèles courants et ne remplacent pas un conseil juridique ou comptable.

Écrites par Yanis Zedira, fondateur de [YZ Automation](https://yz-automation.fr).
