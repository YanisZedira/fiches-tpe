IA

Préparer un agent IA : ce qu’il faut réunir avant de commencer

Un agent IA ne vaut que par ce qu’on lui donne. Les projets qui échouent ont presque toujours le même défaut : on a branché l’outil avant d’écrire les règles. Voici ce qu’il faut réunir.

Les modèles à copier

Le dossier à préparer

1. Les 20 questions que vos clients posent le plus, avec vos réponses exactes.
2. Vos prix, horaires, zones desservies, délais.
3. Ce que l’agent a le droit de faire : répondre, prendre un rendez-vous, envoyer un devis type.
4. Ce qu’il ne doit jamais faire : promettre un prix, donner un avis médical ou juridique, annuler une commande.
5. Les cas où il passe la main à un humain, et à qui.
6. Le ton : tutoiement ou vouvoiement, formules à éviter.
7. Les outils à relier : agenda, CRM, messagerie.
8. Dix vraies conversations passées, pour tester.

La phrase de passage à l’humain

Je préfère que [Prénom] vous réponde directement sur ce point. Puis-je prendre votre numéro ? Il vous rappelle aujourd’hui avant [heure].

Remplacez les éléments entre crochets par les vôtres.

À savoir avant de s'en servir

  • Commencez par une seule tâche, par exemple la prise de rendez-vous. Ajoutez le reste ensuite.
  • Annoncez clairement à vos clients qu’ils échangent avec un assistant automatique.
  • Relisez vingt conversations la première semaine : c’est là que se trouvent les corrections utiles.
  • Ne donnez à l’agent que les accès dont il a besoin.
