Gestion

Avant de signer un devis de site ou d’IA : 10 points à vérifier

Un devis clair protège les deux parties. Ces dix points sont ceux qui manquent le plus souvent, et qui coûtent le plus cher quand ils manquent.

Les modèles à copier

Les 10 points

[ ] Le périmètre est décrit ligne par ligne, avec ce qui n’est pas compris.
[ ] Le prix est ferme, ou les conditions de variation sont écrites.
[ ] Le calendrier de paiement est lié à des étapes, pas à des dates.
[ ] Une date de livraison figure sur le devis.
[ ] Le nombre de retours inclus est précisé.
[ ] Le nom de domaine, l’hébergement et les comptes sont à votre nom.
[ ] Le code source et les contenus vous appartiennent à la livraison.
[ ] Les coûts récurrents sont chiffrés : hébergement, licences, usage de l’IA.
[ ] La maintenance est décrite, avec un prix et un délai d’intervention.
[ ] Vous pouvez arrêter et partir avec votre travail, sans frais cachés.

La question à poser au prestataire

Si nous arrêtons de travailler ensemble dans un an, que me remettez-vous, sous quelle forme, et combien cela me coûte-t-il ?

Remplacez les éléments entre crochets par les vôtres.

À savoir avant de s'en servir

  • Méfiez-vous des abonnements sans fin où le site disparaît si vous arrêtez de payer.
  • Pour un agent IA, demandez le coût par conversation, pas seulement le prix de mise en place.
  • Demandez à voir deux réalisations en ligne et à joindre un client.
