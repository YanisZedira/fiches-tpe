Gestion

Fiche de procédure : le modèle pour déléguer une tâche

On ne peut ni déléguer ni automatiser une tâche qui n’existe que dans la tête du dirigeant. Écrire la procédure prend vingt minutes et fait gagner des heures, quelle que soit la personne ou l’outil qui la reprend.

Le modèle à copier

Le modèle

TÂCHE : [nom]
DÉCLENCHEUR : quand faut-il la faire ? [événement ou fréquence]
RÉSULTAT ATTENDU : à quoi voit-on qu’elle est bien faite ?
DURÉE HABITUELLE : [minutes]

ÉTAPES
1. [action] dans [outil]
2. [action]
3. [action]

CAS PARTICULIERS
- Si [situation], alors [action].
- Si [situation], prévenir [personne].

ERREURS FRÉQUENTES : [liste]
ACCÈS NÉCESSAIRES : [outils, comptes]
RESPONSABLE : [nom]   REMPLAÇANT : [nom]
DERNIÈRE MISE À JOUR : [date]

Remplacez les éléments entre crochets par les vôtres.

À savoir avant de s'en servir

  • Écrivez la procédure en faisant la tâche, pas de mémoire.
  • Faites-la tester par quelqu’un qui ne connaît pas la tâche : ses questions sont vos oublis.
  • Les cas particuliers sont la partie la plus précieuse. C’est sur eux que les automatisations échouent.

Pour aller plus loin

Pour savoir quelles tâches méritent d’être écrites, puis automatisées, chiffrez d’abord ce qu’elles coûtent avec le calculateur du temps perdu.
